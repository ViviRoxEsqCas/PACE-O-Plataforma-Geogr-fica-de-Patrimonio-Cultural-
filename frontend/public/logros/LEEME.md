# Ilustraciones de los logros

Copia aquí una imagen por logro, con el código como nombre de archivo (formatos: `.png`, `.webp`, `.svg` o `.jpg`).
Se recomienda un lienzo vertical 4:5 (por ejemplo 800 × 1000 px) con fondo transparente o liso.

| Código | Logro |
| --- | --- |
| `primera_visita.png` | Primera visita declarada |
| `explorador.png` | Explorador |
| `recorrido_completo.png` | Recorrido completo |
| `primera_valoracion.png` | Primera valoración |
| `primera_opinion.png` | Primera opinión |
| `primera_amistad.png` | Primera amistad |

Si falta una imagen, la interfaz muestra el recuadro de reserva con el nombre del logro. No hace falta tocar el código ni reiniciar el servidor de la API.
